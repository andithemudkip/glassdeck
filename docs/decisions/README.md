# Decisions

ADR-style records of choices that constrain the rest of the project.

One file per decision: `NNNN-short-slug.md`, numbered sequentially, never reused.

Sections: **Context**, **Decision**, **Consequences**. Supersede a prior ADR with a new one — do not edit the old one's outcome. Reference the superseded ADR by number.

Use this for choices that are hard to reverse: MCU family, transceiver, CAN bitrate, display interface, firmware framework, wiring topology, licensing.
