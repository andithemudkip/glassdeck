# Experiments

Chronological log of things we tried — successes AND failures.

One file per non-trivial test: `YYYY-MM-DD-short-slug.md`. Copy `_template.md` to start.

Failures stay. If a later experiment supersedes an earlier one, link forward in the new experiment's `related.experiments` — do not edit or delete the old one. The whole point of this directory is preserving the "we already tried that" knowledge so the next session doesn't re-run dead ends.

When an experiment confirms a fact, promote that fact into `docs/findings/` and reference the experiment.
